# CareSpace 3D：作品展示摘要

狀態：第一版完成。本文件為本機展示與 repository 文案草稿，尚未公開。

## 一句話介紹

從有限的合成室內觀測重建空間，保留自由、障礙與未知，並分析明確尺寸模型下的幾何通行條件。

## Repository description 草稿

A reproducible 3D reconstruction and passage-analysis workbench with RGB-D and learned depth, explicit unknown space, and an interactive viewer.

## 專案解決的問題

室內重建看起來完整，不代表足以判斷通行。遮擋、觀測位置與深度誤差都可能改變路徑判定。
CareSpace 3D 把重建證據、完整幾何參考及目前查詢分開，讓使用者看到判定來自哪些資訊，
並明確區分「可通行」「阻斷」與「未知」。長照居家情境是問題背景，不是臨床有效性主張。

## 已實作的技術

- 程式化場景與 RGB-D／相機內外參生成，保留公尺尺度。
- 像素射線融合與 free／occupied／unknown 體素證據，未知不當成自由空間。
- 已知姿態下，以 DA3METRIC-LARGE 的 RGB＋K 深度替換感測深度，共用融合與規劃流程。
- 圓柱足跡膨脹、離散連通分析、端點與半徑互動查詢。
- 全部觀測、固定間隔與覆蓋選樣比較；保存實驗結果與自訂查詢分開。
- 場景／觀測／模型 revision 與快取一致性檢查，家具配置變動不能沿用舊重建。
- 深度來源追溯與方法差異診斷，保留失敗與負結果。

## 最值得展示的結果

| 同一開放通道 | 融合影格數 | 判定 | 可以說明什麼 |
|---|---:|---|---|
| RGB-D 全部觀測 | 24 | 可通行 | 基線流程可建立已觀測自由路徑 |
| RGB-D 固定間隔 | 8 | 未知 | 較少觀測可能不足以確認通路 |
| RGB-D 覆蓋選樣 | 8 | 可通行 | 相同融合用量，觀測位置改變證據覆蓋 |
| DA3 全部觀測 | 24 | 阻斷 | 學習式深度誤差可導致通道錯誤阻斷 |

覆蓋選樣事先讀取候選 RGB-D，只比較融合用量，不聲稱節省拍攝成本。
這些是同一受控實驗家族的小樣本結果，不是獨立家庭泛化證據。
DA3 沒有預測放行，故錯放／預測放行分母為零，應報 N/A，不可宣稱零風險。

## 展示順序（約三分鐘）

1. 通道開放：RGB-D 全部觀測，還原實驗端點與半徑，顯示可通行。
2. 比較固定間隔與覆蓋選樣：同樣8張，但判定不同。
3. 沙發移至通道：顯示阻斷；強調此配置已重新生成觀測及重建。
4. 觀測不足：顯示未知與候選虛線。
5. 回開放案例檢視 DA3 分歧，說明負結果及參考／重建界線。

操作細節見 [展示指南](demo-guide.md)。

## 限制與成熟度

固定半徑0.30m、高1.20m直立圓柱，平坦已知支撐面、已知相機姿態；
未驗證完整輪椅轉向、坡道、人體動態或真實長者安全。未知姿態不支援。
GPU、真實觸控、讀屏及200%縮放仍未完整驗證。
